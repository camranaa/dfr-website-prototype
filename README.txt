چۆن بیکەیتەوە / How to open
  index.html بکەرەوە لە Chrome، Edge یان Firefox. پێویستی بە ئینتەرنێت نییە.
  Open index.html in Chrome, Edge or Firefox. No internet or server needed.

بەشەکان / Sections
  ماڵپەڕی گشتی ........ index.html (تەنها زانیاری)
  بەشی میدیا (CMS) .... cms.html
  دەروازەی ناوخۆیی ..... portal.html
  ناوی بەکارهێنەرەکان لە پەڕەی چوونەژوورەوە دیارە؛ وشەی نهێنی هەموویان: 1234
  Demo usernames are listed on each login page; password for all: 1234

داتا / Data
  هەموو گۆڕانکارییەک (هەواڵ، داواکاری، شاند، کۆبوونەوە، وێنە) لە وێبگەڕەکەی ئەم کۆمپیوتەرەدا هەڵدەگیرێت.
  Every change (news, requests, delegations, meetings, uploads) is saved in this browser on this computer.
  For a shared multi-user system the same pages connect to a server database (the hosted version).
  Reset to the sample data: portal.html → ڕێکخستنەکان → ئامار → گەڕاندنەوەی داتای نموونە (as admin).
