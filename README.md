# DFR website — prototype

Demo prototype of a redesigned website for the Department of Foreign Relations (KRG), with a media CMS and an internal staff portal.
**This is not the official DFR website.** News items marked "نموونە" and all staff data are samples.

- Public site: `index.html` (information only)
- Media CMS: `cms.html`
- Internal portal: `portal.html`
- Demo logins are listed on each login page (password `1234`) — demonstration only; a real deployment uses SSO + MFA.

Data entered here is saved only in your own browser (localStorage). Reset: portal → admin → ڕێکخستنەکان → ئامار.

Fonts: Noto Naskh Arabic / Noto Sans Arabic (SIL OFL). Flags: flag-icons (MIT).

## Sections (updated 29 Oct 2026)
- Consulate and honorary-consulate pages (`consulate-*.html`, `honorary-*.html`) with the responsible DFR desk and visa-centre information
- Publications library (`publications.html`) with categories, search and filters
- Center for Diplomatic Development sub-site (`cdd.html`, Kurdish / English / Arabic) with training, research, partners & alumni, news, legal documents and contact forms
- CMS roles for desks (`desk.asia`, `desk.eu`, `desk.arab`) and the Center (`cdd.editor`, `cdd.author`)

On this static copy, forms and CMS changes are stored only in the visitor's own browser; nothing is sent anywhere.
